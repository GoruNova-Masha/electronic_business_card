# Электронная визитка — Горюнова Мария

Интерактивная веб-визитка «вайб-кодера» по ТЗ.

## Быстрый старт

1. Откройте `index.html` в браузере или запустите локальный сервер:

```bash
npx serve .
```

2. Визитка доступна по адресу `http://localhost:3000` (или аналогичному).

## Структура

| Файл | Назначение |
|------|------------|
| `index.html` | Главная страница визитки |
| `config.js` | Все тексты и контакты (редактируемый) |
| `admin.html` | Визуальный редактор для обновления `config.js` |
| `css/styles.css` | Стили |
| `js/main.js` | QR-код, vCard, аналитика, анимации |

## Редактирование контента

**Способ 1 — через редактор:** откройте `admin.html`, измените поля, скачайте `config.js` и замените файл в проекте.

**Способ 2 — вручную:** отредактируйте `config.js` напрямую.

После публикации укажите финальный URL в `config.js` → `seo.url` — он используется для QR-кода и Open Graph.

## Публикация

Подойдут любые статические хостинги:

- [GitHub Pages](https://pages.github.com/)
- [Netlify](https://www.netlify.com/)
- [Vercel](https://vercel.com/)

Загрузите все файлы проекта. Короткую ссылку можно настроить через свой домен или сервис сокращения ссылок.

## QR-код

Готовый файл для печати: `assets/vizitka-qr.png` (1024×1024 px).

На странице QR также генерируется динамически. Кнопка **«Скачать QR (PNG)»** сохраняет изображение для визиток и сувениров.

После публикации укажите `seo.url` в `config.js` и перегенерируйте QR:

```bash
python scripts/generate_qr.py
```

## vCard

Кнопка **«Сохранить в контакты»** скачивает файл `.vcf` со всеми контактами.

## Аналитика

В `config.js` укажите:

- `analytics.yandexMetrikaId` — номер счётчика Яндекс Метрики
- `analytics.googleAnalyticsId` — ID Google Analytics (формат `G-XXXXXXXX`)

События: клики по Telegram, e-mail, телефону, скачивание vCard и QR.

## SEO и превью в мессенджерах

1. Укажите `seo.url` после публикации.
2. Для Open Graph замените `assets/og-preview.svg` на PNG 1200×630 (`assets/og-preview.png`) — так превью корректнее отображается в Telegram и соцсетях.

## NFC-метка (опционально)

Запишите на NFC-метку URL опубликованной визитки любым NFC-редактором (например, NFC Tools).
